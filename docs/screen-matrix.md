# Матрица экранов

Все 28 исходных описаний сохранены в source-host-descriptions.txt и source-player-descriptions.txt; PDF остаются первичным источником. Все маршруты: `/preview/warm-v3/?screen=ID`. Прямой маршрут — инструмент дизайнера, он не меняет серверные разрешения или фазу. Host-вход требует PREVIEW-HOST; player-вход — имя, команда и место 1–5. Ошибки сети показываются уведомлением; пустое состояние сообщает следующий шаг. Данные демонстрационные, не контракты основной платформы.
