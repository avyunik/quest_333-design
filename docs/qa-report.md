# QA Warm V3

Среда: Python 3.12, Node 24, Playwright 1.62.1, системный Chromium. Проверки запускаются на настоящем Python API, не на статических mock-ответах браузера.

## Результаты

- `npm ci --cache /tmp/warm-npm --ignore-scripts` — установка по lockfile успешна.
- `npm run lint` — синтаксическая проверка JavaScript успешна. Это не полноценный линтер стиля и не typecheck.
- `npm test` — 7 серверных тестов: права ролей, подтверждение координаты, скрытие полки, принадлежность барабанов и только число совпадений, тайные голоса и ничья, рисунок/приватная картинка, очередь рычагов, logout и недоступность серверного исходника.
- `npm run build` — сборка frontend в dist успешна; приложение по-прежнему требует API.
- `npm run test:browser` — 28 экранов × 4 viewport = 112 снимков. Размеры 1440×900, 1280×900, 768×1024, 390×844. Ноль pageerror и горизонтальных переполнений документа. Отчёт `qa/browser-results.json`.
- Браузерные действия: неверный/правильный номер; показ полки → скрытие → 14 размещений кнопочным способом → проверка; касса → изменение барабана → рычаг → число совпадений; роль → подтверждение → одно слово; canvas → ответ другого участника → принятие ведущим; голосование → ничья → новый тур; финал → явный preview-переход к итогам.

Визуально просмотрены исходные контактные листы и снимки компонентов V3. После первого прогона увеличены мобильные карточки полки; итоговый прогон пересоздаёт все снимки. Общие правила: бумага читается на светлом фоне, янтарные предметы на деревянной полке, обе команды у ведущего, ясный статус ожидания. На десктопе длинные материалы могут требовать вертикальную прокрутку, на телефоне команды складываются в одну колонку. В кассе предусмотрена внутренняя горизонтальная прокрутка барабанов.

## Ограничения и непроверенное

Нет исходных видео/аудио: воспроизведение, субтитры, autoplay restrictions и настоящий ended-переход не проверены. Нет production-платформы: WebSocket, баланс, ключи, мобильные физические устройства, реальные пользователи, полноценный accessibility-аудит и регрессия V2 не проверены. Touch-альтернатива использует обычные кнопки; не заявляем полноценное touch drag-and-drop. Фото команды заменено явно подписанной открыткой. Снимки не являются автоматическим сравнением с эталонным дизайном.

Безопасность preview не равна production: демокод и выбор места открыты для исследователя. При этом прямое действие игрока от имени ведущего и получение секретных DTO проверяются отрицательными тестами. Статический сервер ограничен frontend и публичными ассетами, приватные SVG не включаются в dist.

Дополнительный touch-прогон: `npm run test:touch` — эмуляция мобильного устройства 390×844 с hasTouch, выбор карточки через tap и размещение в слот. Сохранены `state-shelf-memorize-touch.png`, `state-shelf-touch-placement.png`, `state-vote-tie.png`; вместе с `pilot-cash-attempt.png` это четыре дополнительных снимка к основной серии из 112. Подтверждено кнопочное touch-управление; нативное перетаскивание пальцем не заявляется.
