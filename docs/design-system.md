# Дизайн-система

Графитово-синий фон, бумажные материалы, латунные контуры, тёплая подсветка. Бирюза только для основных действий, красный для вывески и опасных операций. CSS-токены в style.css: фон, панели, текст, акценты, интервалы, радиусы, тени. Системный sans для интерфейса, Georgia для бумажных документов. Числа таймера табличные.

Компоненты: общий Shell, каталог экранов, заголовок эпизода, команды, служебная панель, бумажный документ, карточка предмета, полка с 14 ячейками, барабаны, уведомление и формы. Нативные button/input/select/details и canvas, видимый focus, aria-live, подписи полей. Области касания не меньше 44px. Сетка ведущего 2+1, команды 1+1; на 900px одна колонка, на 600px упрощённая навигация. Проверка 1440×900, 1280×900, 768×1024 и 390×844. Предпочтение reduced-motion учитывается.

Предметные доминанты: почтомат — сетка; книга — бумага; будка — аудиопульт; полка — дерево и товарные карточки; станция — шкалы; карта — точки пути; пазл — доска; касса — механические барабаны; развилка — карточки дорог. Критический текст всегда HTML.
