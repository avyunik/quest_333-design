# Недостающие материалы

Готовы: самостоятельная ночная станция (WebP, mobile WebP, JPEG fallback), 6 оригинальных SVG-иконок, 5 серверно защищённых геометрических ассоциаций. Предметы полки сейчас являются CSS/SVG-карточками с настоящими HTML-названиями; это функциональные fallback-объекты, не фото товаров.

| P1 | Финальный ролик | 1920×1080 MP4/WebM + VTT | Авторская концовка, согласованная с выбранным маршрутом | host-13/player-14 |

Общий фон уже создан доступным image generation. Нет заимствований UI или нарезки исходных скриншотов. Дополнительные художественные сцены остаются улучшением визуальной полноты; текущий прототип использует один общий фон и предметные компоненты. Источники прав на исходные документы и медиа нужно подтвердить перед публикацией продукта.
