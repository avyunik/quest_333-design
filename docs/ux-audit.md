# UX-аудит Warm V3

Источник: оба PDF полностью извлечены pdftotext; просмотрены контактные листы всех 13 host, 15 player и пяти visual_references. Исходники не изменены. В репозитории нет приложения, V2, API, сохранений или игровых конфигураций. Это самостоятельный preview; интеграция является отдельным этапом.

| Приоритет | Наблюдение и причина | Решение V3 | Ограничение |
|---|---|---|---|
| P0 | Скрытые ответы могут утечь при передаче полного состояния | Сервер фильтрует данные по cookie-сессии; ключи кассы, эталон полки, чужие картинки не поставляются игроку | Демокод ведущего открыт намеренно; не production-авторизация |
| P0 | Возврат на экран запоминания раскрывает полку | Фаза и срок определяются сервером; после скрытия источник отсутствует в API | Время демонстрационное, 60 с |
| P1 | PDF входа ведущего повторяет пролог | Форма имени и отдельного кода ведущего | Код PREVIEW-HOST опубликован только для preview |
| P1 | Роль и право на координату неочевидны | Выбор роли → подтверждение ведущим → координата только загадывающему | Запретные слова неизвестны; базовая проверка одного слова без цифр |
| P1 | Drag-only исключает touch/клавиатуру | Выбор карточки кнопкой и выбор ячейки; HTML drag дополнительно; удаление и проверка | Эталон 14 предметов — отдельная fixture, не извлечён из логики V2 |
| P1 | Рисующий может случайно раскрыть ответ | Загадка приходит только активному; ответ вводит другой игрок; canvas одного цвета | Очередь демонстрационная, активный участник №1 |
| P1 | Голоса видны преждевременно | Игрок видит только свой голос и число готовых; итог объявляет ведущий | Тай-брейк новым туром, а не произвольным выбором |
| P1 | Обратная связь теряется среди панелей | aria-live уведомления, история попыток, видимые причины блокировки | Синхронизация polling, не WebSocket |
| P1 | Пять барабанов при неизвестном размере группы | Пять явно подписанных владельцев, сервер проверяет права | Группы <5 не эмулируются без правил основной платформы |
| P1 | Не заданы зависимости рычагов, ключи и маршрут | Явные тестовые конфигурации на сервере | Требуется заменить конфигурациями основной платформы |
| P1 | Нет медиафайлов роликов и аудиозаписи | Явное сообщение об отсутствии и отдельный preview-переход | Реальное воспроизведение/ended невозможно проверить без медиа |
| P2 | На скриншотах плотный мелкий UI | Раздельные смысловые зоны, 16px текст, мобильная одна колонка | Скриншоты служат ориентиром структуры |
| P2 | Неясный следующий шаг | У каждой игры короткие правила, кнопка действия и статус | Прямые ссылки в индексе — инструмент дизайнера |

Пять референсов определяют дерево, состаренную бумагу, латунь, тёплые лампы и локальный янтарный свет. Сохраняем плотность ведущего, но ответы и подсказки раскрываем осознанно. Не используем скриншоты как UI или нарезку панелей.

Дополнительные решения после QA:

- P1: подсказки почтомата хранятся отдельно по командам; обмен через общее поле исключён.
- P1: приватные ассоциации отдаются авторизованным endpoint, а не публичным URL ассета; переключение активного игрока доступно ведущему.
- P2: на 390px исходная сетка полки 7×2 делала подписи и области касания мелкими. Оба состояния на телефоне используют четыре колонки с постоянными номерами мест и тем же линейным порядком 1–14.
- P2: в референсе кассы изображено шесть букв, но обязательный инвариант и исходные игровые экраны задают пять барабанов со словами. Выбраны пять барабанов; референс используется для материалов и света.
- P1: описание player-13 говорит об общем выборе, инвариант уточняет тайный голос. До подведения итога игрок получает только собственный голос и число готовых, ведущий — распределение.

Открытые P1 для production: идентификация/авторизация, реальные медиа, ключи и сценарии, матрица влияния рычагов и полная очередь загадок. Они не скрываются за демонстрационной реализацией и не являются изменениями V2.
