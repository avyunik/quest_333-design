# Контроль смысловой целостности

Проверяются изображения и их сюжетный состав; программная игровая логика в этой ревизии не меняется.

| Область | Критерий |
|---|---|
| Пролог | Конференция, современный автобус, сбой устройств; нет преждевременного объяснения про вышку |
| Почтомат | Два разных вида; 5×5; одинаковые открытые А1/А4/Б2/В1/Г3/Д5; В3 только у загадывающего/ведущего |
| Записник | Открытые страницы с шестью сюжетными абзацами; маркированные смены 3/1/4/2/0/6; даты и время — отвлекающие числа; нет списка контактов и готового номера у игрока |
| Будка | Первое раскрытие причины: Р-33 и резервное питание; запись связана с находкой номера |
| Полка | 14 мест; две фазы; ключ от сервисной служит сюжетной наградой; эталон скрыт в восстановлении |
| Шкалы | Аналоговый насос, топливо; щиток заправки не отключает автономную вышку |
| Карта, рассказчик | Личная сюрреалистическая многозначная иллюстрация и устное описание; нет точки-ответа, выбора вариантов или вставки в маршрут |
| Карта, команда | Шесть конкретных вариантов, один верный; четыре места итогового пути; нет личной картинки активного игрока |
| Карта, второй шаг | Мария вместо Алексея; другая личная картинка; шесть других вариантов; первая часть пути уже собрана |
| Пазл | Текстовая загадка, одноцветный рисунок, ответ «компас» только у ведущего; аналоговая навигация имеет сюжетный смысл |
| Касса | Пять слов и владельцев; игроку только общее число совпадений; сейф связан с ключами и документами старого автобуса |
| Развилка | Три способа выхода связаны с уликами; нет случайного выбора дороги; каждый голосует отдельно; чужие голоса скрыты у игрока |
| Финал | Старый механический автобус, южный выезд, конференция; новый автобус не оживает без объяснения |

Детали, которые нельзя надёжно считать по уменьшенному обзорному листу, проверяются по полноразмерному PNG. Наличие всех состояний и размеры файлов проверяются при упаковке; визуальная оценка не является программным тестом механик.

## Результат проверки комплекта

- Проверено наличие32PNG:13ведущего и19состояний игроков. Все файлы декодируются,1536×1024; размеры иSHA-256 записаны вmanifest.json.
- Полноразмерно сверены ключевые изменения: записник/шесть смен/решение314206, тайнаяВ3 и шесть открытых ячеек в двух видах почтомата, разделение личной иллюстрации и вариантов карты, смена активного игрока и набора вариантов на шаге2, финальные доказательства и индивидуальный голос.
- Все32изображения просмотрены на обзорных листах; для карты создан отдельный лист сравнения четырёх состояний.
- После проверки исправлены подписи ролей рассказчика, сохранение команды между шагами карты, источники улик в голосовании, смысл нормализации/сброса шкал и найденное проводное сообщение на полке.
- Первая серия, исходные PDF и код интерактивного прототипа не менялись. Это визуальная ревизия; программная реализация и её тесты под новый сюжет не заявляются.
- Весь набор упакован вZIP; проверены13/19PNG внутри и целостность архива. Вспомогательные имена/числа интерфейсных фикстур и мелкие генеративные подписи требуют финальной вычитки; канон механик и текста ребуса зафиксирован вSTORY.md.
