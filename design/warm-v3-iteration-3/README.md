# Warm Redesign V3 — итерация 3

**36 новых PNG: 13 экранов ведущего и 23 состояния игроков.** Все 28 исходных экранов сохранены по назначению; восемь дополнительных состояний раскрывают роли и результаты. Каждое изображение сгенерировано заново из текстового задания. Изображения предыдущих серий не редактировались и не передавались генератору как основа.

## Как посмотреть

- На GitHub: папки [ведущего](host/) и [игроков](player/).
- [Скачать весь комплект ZIP](../warm-v3-iteration-3.zip), распаковать и открыть **index.html** двойным щелчком. Галерея работает локально, позволяет отфильтровать роли и открыть PNG в полном размере.
- Быстрый обзор: [ведущий](contact-sheets/host-overview.jpg), [игроки — часть 1](contact-sheets/player-overview-1.jpg), [часть 2](contact-sheets/player-overview-2.jpg).
- Сравнения: [ключевые механики](contact-sheets/mechanics-review.jpg), [две роли карты](contact-sheets/route-role-comparison.jpg), [рисование и общая фотография](contact-sheets/drawing-role-comparison.jpg).

Это цельные изображения дизайнов и галерея для просмотра. Изображённые игровые кнопки не являются работающими компонентами; механики новой сценарной редакции ещё не перенесены в программный прототип.

## Что изменилось

- **Почтомат:** словесные заголовки всех строк и столбцов, приватная пара понятий загадывающего, три уже открытые ячейки с предметами, отдельный экран находки записника.
- **Телефонная книга:** записник с шестью записями и ребусом по третьим числам; готовый номер не показан игроку.
- **Шкалы:** температура, давление, влажность и заряд ручного привода открывают служебный бокс; отдельное состояние показывает результат и возвращение водителя.
- **Карта:** активный описывает личную ассоциативную картину; остальные выбирают из шести вариантов. Показаны две последовательные смены ролей и материалов.
- **Пазл:** сохранено рисование по текстовой загадке из PDF. Каждый угаданный рисунок открывает фрагмент общей фотографии с причиной сбоя.
- **Развилка:** личное тайное голосование по найденным уликам завершает общую историю поездки на конференцию.
- **UI:** спокойные панели, крупные подписи, ясные действия, меньше фоновой сценографии и декоративного шума.
