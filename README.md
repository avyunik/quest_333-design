# Заправка 3:33 · Warm Redesign V3

Самостоятельный интерактивный прототип: **13 экранов ведущего + 15 экранов игрока**, индекс «Все экраны», прямые маршруты `/preview/warm-v3/?screen=host-05` и аналогичные ID из SCREENS.json. Ветка `feat/warm-redesign-v3`. Код основной платформы отсутствует; исходные материалы сохранены без изменений.

## Запуск

Требуется Python 3.10+; для самого приложения пакеты не нужны.

```sh
cd /workspace/quest_333-design
python3 server.py --port 3333
```

Откройте путь `/preview/warm-v3/` на сервере через доступный в вашей среде способ просмотра. Host: имя и код **PREVIEW-HOST**. Player: имя, команда, место 1–5. Для совместной проверки используйте разные профили/контексты браузера: одна cookie-сессия на профиль. Данные обеих команд общие для всех посетителей процесса; перезапуск очищает игру. В навигации «Текущий этап» открывает выбранный ведущим эпизод; дизайнерский каталог открывает любой экран, сохраняя права и фазу.

## Реализовано

Нативные HTML/CSS-компоненты, общая дизайн-система, генерированный фон ночной станции и оригинальные SVG. Выбор и подтверждение ролей, личная координата, 5×5, памятка с вводом номера, ввод фразы, серверная фаза полки и 14 мест с карточками/drag/click/удалением/проверкой, рычаги с очередью и допустимыми действиями, личные ассоциации, маршрут, одноцветное рисование с проверкой ведущим, пять барабанов с владельцами и числом совпадений, тайные голоса/ничья/новый тур, демонстрационные итоги и скачивание открытки. Пульт ведущего видит обе команды и позволяет выбрать команду в фокусе. Polling синхронизирует роли, фазы и действия между браузерами.

Это preview, а не production-система: вход по известному коду и выбор места не являются защищённой идентификацией. Сервер не отдаёт игроку ключ ведущего, эталон скрытой полки, чужие голоса и приватную картинку другого активного игрока. Публичный JS не содержит ответных ключей; серверные fixtures недоступны через статический HTTP.

## Проверки

Node 20+ для сборки/синтаксиса. Для браузерного QA: `npm ci` и установленный Chromium. В подготовленной среде Playwright уже доступен; системный Chromium — `/usr/bin/chromium`. На другой машине укажите `CHROMIUM_PATH` или установите Chromium. Отдельного typecheck нет: проект использует обычный JavaScript без TypeScript.

```sh
npm run lint
npm test
npm run build
# при запущенном python3 server.py
npm run test:browser
```

`build` собирает фронтенд в `dist`, но не заменяет Python API; отдельно как статический сайт прототип не работает. `test:browser` сбрасывает общую демонстрационную сессию, проходит сценарии и пересоздаёт снимки всех 28 экранов на 1440×900, 1280×900, 768×1024, 390×844. Результаты: `qa/browser-results.json`, `qa/screenshots/`. Тесты Python поднимают собственный сервер на свободном порту.

## Перед интеграцией

См. `docs/integration.md`, `docs/ux-audit.md`, `docs/screen-matrix.md`, `docs/design-system.md`, `docs/qa-report.md`, `assets/asset-manifest.json` и `docs/assets-needed.md`.

Не приложены исходные ролики и аудиозагадка: есть честные места для медиа и отдельный preview-переход к результатам. Нет проверки реального видео→ended, настоящей авторизации, production WebSocket, оригинальных ключей/влияний рычагов, полноценного игрового таймера, системы баллов и фото команд. Пять игроков на команду, ключи и допустимые действия — явно демонстрационная конфигурация. Поддержка меньшей команды требует правил основной платформы. Не заявляем сохранность V2 по тестам: её кода здесь нет, а дизайн-исходники не менялись.

Дополнительная проверка touch-нажатий: `npm run test:touch` (также меняет общую demo-сессию). Все QA-снимки сохранены в репозитории, поэтому каталог `qa/` заметно увеличивает его объём.
